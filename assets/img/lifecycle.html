Quality Gates

Eight gates, top to bottom. No gate can be skipped.

01
Intent
Lead describes the objective. Coordinator validates scope and feasibility.
Coordinator
Output: validated scope
02
Plan
Decompose into tasks with dependencies, complexity estimates, and model tiers. Lead approves.
Coordinator Planner
Output: approved prd.json
03
Recon
Scan codebase structure, detect platform, map conventions and risk areas.
Recon Worker
Output: recon data
04
Execute
Workers implement tasks in parallel. Post-edit diagnostics catch regressions at the source.
Backend Frontend Fullstack
Output: code changes + structured debrief
05
Code Review
Independent reviewer analyzes the diff for bugs, standards violations, and security issues. Never saw the original prompt.
Code Reviewer
Verdict: PASS / FAIL
06
Test Verification
Testing worker writes and runs unit, kernel, or integration tests against the changes.
Testing Worker
Verdict: tests pass / fail
07
Visual Review
Browser-based validation of UI rendering, layout, and accessibility. Skipped for backend-only tasks.
Visual Reviewer
Verdict: PASS / FAIL
08
Delivery
Smart revision: accept, targeted fix, full rework, or escalate. Report generated, dashboard updated.
Coordinator Report Writer
Output: report + dashboard
